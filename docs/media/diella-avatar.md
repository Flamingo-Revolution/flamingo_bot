# Diella avatar media record

- Authorization: the project owner confirmed that the source media may be reused
  in this project.
- Treatment: centered 360×360 head-and-shoulders crop; all source audio removed.

The exact source URL, selected interval, and internal authorization record are
retained outside the public repository. Operators must preserve that private
record or replace the assets with media whose reuse basis they can document.

Generated public assets:

- `frontend/public/media/flamingo-avatar-loop.mp4`: H.264, 10.000 seconds,
  360×360, video-only.
- `frontend/public/media/flamingo-avatar-loop.webm`: VP9, 10.000 seconds,
  360×360, video-only.
- `frontend/public/media/flamingo-avatar-poster.webp`: reduced-motion/fallback
  poster from the selected interval.

The source download is a temporary build input and is not tracked. The public
assets may be used only under the project's authorization; this repository does
not grant a general license to third parties.
